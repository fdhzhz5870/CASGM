# CASGM Project Page

Paper project page for **CASGM: Co-Visible Area Guided Optical-SAR Matching with Significant Geometric Differences** (under review, ISPRS JPRS 2nd round).

- Code: https://github.com/fdhzhz5870/CASGM
- Dataset: https://huggingface.co/datasets/PuYuchi/GeoMS-OS

## Local preview

Open `index.html` directly, or serve:

```
cd web_casgm
python -m http.server 8000
```

## Deploy to GitHub Pages

See index.html footer for the visitor counter (CounterAPI `casgm-site`).
